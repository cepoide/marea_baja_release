## 🛠️ Herramientas y Tecnologías
* **Motor:** [Godot Engine 4.7.1 Stable](https://godotengine.org/)
* **Modelado 3D:** [Blender](https://www.blender.org/)
* **Plugins de Godot:**
  * **[Sky3D](https://store.godotengine.org/asset/tokisangames/sky3d/):** Para la generación y control del cielo/entorno.
  * **[Dialogic 2](https://dialogic.cohq.net/):** Para el sistema de diálogos e interacción con el NPC.
* **Assets / Texturas:**
  * [Kenney Prototype Textures](https://kenney.nl/assets/prototype-textures) - Utilizadas para el bloqueo (blockout) del nivel de pruebas.
  * [Character Template by erisesra](https://erisesra.itch.io/character-templates-pack?download) - Personaje y NPC

## 🎮 Controles
Dentro del nivel de pruebas, podés utilizar los siguientes controles para moverte e interactuar:

* **`W` `A` `S` `D`** - Caminar
* **`Espacio`** - Saltar
* **`E`** - Interactuar (por ejemplo, para hablar con el NPC)
* **`F`** - Prender / Apagar la linterna
